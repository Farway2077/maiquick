# 舞萌快捷更新

用户需求：安卓使用；首次粘贴公众号玩家二维码识别的字符串，之后不用重复复制，点按钮更新水鱼成绩。

依据：水鱼新版导入指南的 UID/友人对战方式，以及 maimai.py ArcadeProvider 文档。有效的 SGWCMAID 字符串可交换为长期加密 UID；这个方式只获取达成率与 DX 分，不能获取新的 FC/FS。机台协议实现 maimai-ffi 0.7.1 没有 Android 构建，必须运行于个人后台。

最终实现：原生 Java APK，内置 PRoot 与完整 Python 3.12 Linux 用户环境，完全在手机本地执行 maimai-ffi。不会启动网络服务器，不需要外部后台或 Termux App。首次启动离线解压环境，Token 与长期加密 UID 再通过 Android Keystore 加密保存。凭据通过进程 stdin 传递，不进入命令行或日志。手机直接读取水鱼曲目及旧成绩，按 ID/谱面映射并保留旧 FC/FS 与较高的已存成绩；成功上传后显示服务端接受的记录数。宴谱及未匹配曲目单独计数。

用户明确要求手机独立使用，无电脑/服务器依赖。探索后采用 APK 内嵌运行环境的方案，Android target 28 支持这种执行模型，最低 Android 8；实际 Android 14 x86_64 模拟器运行通过。普通手机包为 ARM64，ARM64 实机尚需用户验证。安装环境约占 200 MB，APK 约 51 MB。

验证：13 个 Python 测试覆盖曲目映射、分数换算、旧标记与高分保护、拒绝重定向、账号改变、部分成功回执和长期 UID 复用；模拟器验证原生库、Python 执行、公开水鱼 API 与加密持久化；界面、首次绑定表单、设置与桌面快捷方式另外检查。合成成绩仅用于测试，不得上传真实水鱼账户。
