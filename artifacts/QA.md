# MaiQuick 0.1.0 验证记录

日期：2026-10-06。

交付包：`maiquick-0.1.0-arm64.apk`，个人密钥签名的 release 包。

## 已验证

- Python 核心测试：13 项通过。覆盖曲目 ID / SD / DX 映射、达成率精度、旧 FC/FS 及更高分保留、去重、未知和宴谱跳过、空成绩阻断、长期 UID 更新、错误账号阻断、旧成绩读取失败及 HTTP 重定向不上传、部分回执拒绝、无效 Token 不联网。
- Release 构建通过。Android Lint：0 errors，7 warnings；包含特意保留的 target SDK 28 侧载提示、中文文本本地化提示，无编译或 API 兼容性错误。
- Android 14 x86_64 模拟器：2 项真实运行检查通过。内置 PRoot 启动 Linux Python 3.12，实际导入 maimai-ffi，访问水鱼公开曲目 API；Android Keystore AES-GCM 保存后重新读取凭据。
- 主界面和首次绑定表单已查看。通过模拟绑定数据添加桌面快捷按钮，点击后无需第二次点击即可开始更新。
- 无效测试 Token 返回账号验证失败，恢复按钮可操作，未显示成功、未读取机台成绩、未上传。测试数据已清除。
- Android 崩溃日志为空。
- 安装包仅包含 ARM64 原生库和 ARM64 运行环境；没有预填用户 Token、二维码或私钥。APK 签名经 apksigner 验证。

## 尚未验证

- ARM64 真机运行；手机首次启动仍需确认运行环境兼容性。
- 用户有效二维码的首次 UID 绑定以及用户真实账号成绩读取、上传。未拿到有效二维码，未把测试或虚假成绩发到用户账号。
- 官方机台接口未来的变更、维护及网络限制。

快捷 UID 模式不能获取新 FC/FS，已有标记在上传时保留。二维码只用于首次换取长期 UID，不持久保存；清除应用数据或更换舞萌账号需重新绑定。
